개인정보처리방침 (Privacy Policy)

시행일: 2026-10-10

1. 앱 개요

AOD Daily Issue Studio(이하 "앱")는 YouTube 채널 "지금 한컷" 운영자가 본인의 PC에서만 실행하는 개인용 도구입니다. 운영자 외 다른 사용자의 데이터를 수집하지 않습니다.

2. 접근하는 Google 사용자 데이터

운영자가 Google OAuth로 동의한 범위 안에서 다음 데이터에 접근합니다.

  • YouTube 채널 정보(채널 ID, 채널명)
  • 운영자가 제작한 영상의 업로드 및 메타데이터(제목, 설명, 공개 상태, 게시 예약) 관리
  • 운영자 채널 영상의 조회수, 시청 시간 등 YouTube Analytics 성과 지표

3. 데이터 사용 목적

위 데이터는 운영자 본인 채널에 영상을 업로드하고, 업로드 상태를 확인하며, 성과를 분석해 다음 콘텐츠 제작에 반영하는 용도로만 사용합니다.

4. 저장 및 보안

OAuth 토큰과 데이터는 운영자 PC에만 저장되며, 토큰은 Windows DPAPI로 암호화됩니다. 외부 서버로 전송하거나 제3자와 공유·판매하지 않습니다.

5. Google API 서비스 사용자 데이터 정책 준수

이 앱이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용(Limited Use) 요구사항을 포함한 Google API Services User Data Policy를 준수합니다. 이 앱은 YouTube 서비스 약관을 따르며, Google의 개인정보 처리에 대해서는 Google 개인정보처리방침을 참고하세요.

6. 접근 권한 철회 및 삭제

Google 계정 보안 설정에서 언제든 앱의 접근 권한을 철회할 수 있습니다. 앱 설정의 연결 해제 기능으로 로컬에 저장된 토큰과 데이터를 삭제할 수 있습니다.
